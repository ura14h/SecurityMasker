## 実OpenAI WebSocket／HTTP

- tool calls per turn: 8
- WebSocket connections: 1
- WebSocket completed responses: 14
- WebSocket wall time: 84,033.9 ms
- HTTP wall time: 115,698.8 ms
- 観測差: WebSocketが27.4%短い
- 各tool resultのmask、最終responseの復元、alias非残存: 成功

同日の事前測定では、WebSocket／HTTPが91,565.1／80,223.8 msと
125,833.3／81,880.3 msになりました。機能条件はどちらも成功しており、外部serviceの負荷、
prompt cache、生成時間をtransport固有の時間から分離できません。合格値だけを選ぶ運用を避ける
ため、[ADR-0018](../../adr/0018-support-codex-responses-websocket.md)を修正し、wall timeの生値と
差は記録するが単回の大小関係は合否条件にしないことを明記しました。

## 外向きnetwork遮断

online gate完了後、同じimageを新しいcontainerとして`--network none`で起動しました。testは
IFF_UPな非loopback interface、IPv4 default route、IPv6 default routeがないことを構造検査し、
その内側でGateway、local mock、実CLIのprocess全体を実行しました。

- CodexはResponses WebSocketを使用した
- Claude CodeはAnthropic Messages routeを使用した
- local mockへ届いた最終payloadに合成原文は存在しなかった
- client出力では合成原文が復元され、aliasは残らなかった
- 両CLIを必須とし、missing／skipを合格として扱わなかった
